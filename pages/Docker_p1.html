Docker - Phần 1: Định nghĩa, Image, Container và Cú pháp cơ bản

Ngày đăng: 08/04/2026 Chuyên mục: DevOps & Containerization
#docker #container #image #devops #cli

I. Docker là gì?

Docker là công cụ mã nguồn mở dùng để đóng gói và chạy ứng dụng trong các môi trường cách ly gọi là container. Docker cho phép nhà phát triển triển khai ứng dụng một cách nhất quán trên mọi hệ thống (từ máy tính cá nhân đến máy chủ).

Một máy vật lý có phần cứng (ổ đĩa, CPU, RAM) chạy hệ điều hành – gọi là máy host. Trên máy host này, ta cài Docker. Khi muốn chạy một ứng dụng, Docker sẽ tạo ra một container – môi trường cách ly chứa đầy đủ thư viện, gói phụ thuộc để ứng dụng hoạt động. Docker có thể tạo nhiều container khác nhau, mỗi container cách ly hoàn toàn, không tương tác trực tiếp với nhau.

Container giống như một máy ảo hạng nhẹ, nhưng có bản chất khác biệt: thay vì chạy một hệ điều hành riêng, container dùng chung kernel của máy host, chỉ bổ sung thêm các thư viện cần thiết. Nhờ đó container nhẹ hơn, khởi động nhanh hơn và ít tốn tài nguyên hơn so với máy ảo truyền thống.

⚙️ So sánh Docker với máy ảo (VM)

  • Máy ảo: Mỗi VM chạy một hệ điều hành riêng, chiếm nhiều tài nguyên (RAM, CPU, disk).
  • Docker container: Chia sẻ kernel host, chỉ thêm các tầng thư viện cần thiết → nhẹ hơn, khởi động nhanh (vài giây).

II. Cài đặt Docker

Dưới đây là hướng dẫn nhanh cài Docker trên các hệ điều hành phổ biến.

1. Windows 10

# Kích hoạt Hyper-V (chạy PowerShell với quyền Admin)
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All

# Sau đó tải Docker Desktop từ:
# https://hub.docker.com/editions/community/docker-ce-desktop-windows

# Kiểm tra cài đặt
docker --version

2. Ubuntu

sudo apt update
sudo apt install apt-transport-https ca-certificates curl software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu bionic stable"
sudo apt update
apt-cache policy docker-ce
sudo apt install docker-ce
sudo systemctl status docker
sudo usermod -aG docker $USER
# Cài thêm docker-compose
sudo apt install docker-compose
sudo apt install virtualbox   # nếu cần

3. CentOS 7

sudo yum install -y yum-utils device-mapper-persistent-data lvm2
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install docker-ce
sudo usermod -aG docker $(whoami)
sudo systemctl enable docker.service
sudo systemctl start docker.service
# Cài Docker Compose
sudo yum install epel-release
sudo yum install -y python-pip
sudo pip install docker-compose
sudo yum upgrade python*
docker-compose version

III. Docker Image

Docker Image là một gói phần mềm chỉ đọc (read-only), chứa mọi thứ cần thiết để chạy một ứng dụng: mã nguồn, thư viện, biến môi trường, tệp cấu hình. Image được xây dựng từ các layer và không thể thay đổi sau khi tạo. Khi một image được chạy, thể hiện thực thi của nó được gọi là container.

Các lệnh cơ bản với Docker Image

# Liệt kê các image có trên máy
docker images

# Tìm kiếm image trên Docker Hub
docker search <tên_image>

# Tải image từ registry
docker pull <tên_image>[:<tag>]   # tag mặc định là 'latest'

# Xóa image (cần dừng container liên quan trước)
docker image rm <tên_image>:<tag>
# hoặc xóa bằng ID (chỉ cần vài ký tự đầu)
docker image rm <image_id>

# Lưu image ra file .tar
docker save --output <tên_file.tar> <tên_image>

# Tạo image từ file .tar
docker load -i <tên_file.tar>

# Đổi tên image (tạo tag mới)
docker tag <image_id> <tên_mới>:<tag_mới>

IV. Docker Container

Container là một thể hiện đang chạy của một Docker Image. Container có thể được tạo, khởi động, dừng, di chuyển và xóa. Mỗi container đều cô lập với nhau và với host, nhưng có thể giao tiếp qua network được cấu hình.

Các lệnh cơ bản với Docker Container

# Tạo và chạy container từ image
docker run [tùy_chọn] <tên_image> [lệnh] [tham_số]
# Các tùy chọn thường dùng:
# -i : giữ STDIN mở (interactive)
# -t : cấp terminal (kết hợp -it để có shell)
# --name : đặt tên cho container
# -h : đặt hostname cho container
# --rm : tự động xóa container khi dừng
# -d : chạy ngầm (detach)

# Ví dụ: chạy Ubuntu với shell tương tác
docker run -it ubuntu:latest

# Ví dụ: đặt tên và hostname
docker run -it --name "XYZ" -h centos1 centos:latest

# Ví dụ: chạy lệnh ls và tự xóa sau khi kết thúc
docker run -it --rm debian ls -la

# Xem danh sách container đang chạy
docker ps

# Xem tất cả container (kể cả đã dừng)
docker ps -a

# Thoát container nhưng vẫn chạy ngầm: Ctrl + P + Q
# Thoát và dừng container: gõ `exit`

# Khởi động lại container đã dừng
docker start <tên_container> hoặc <container_id>

# Kết nối vào container đang chạy
docker attach <tên_container>

# Dừng container đang chạy
docker stop <tên_container>

# Xóa container đã dừng
docker rm <tên_container>

# Xóa container đang chạy (mạnh)
docker rm -f <tên_container>

Lưu container thành image (commit)

# Container phải ở trạng thái dừng (exited)
docker commit <tên_container> <tên_image_mới>:<tag>

# Ví dụ: lưu container ubuntu thành image ubuntu-ssh:V1
docker commit ubuntu ubuntu-ssh:V1

Thực thi lệnh từ bên ngoài container (docker exec)

# Chạy một lệnh trong container đang chạy mà không cần attach
docker exec <tên_container> <lệnh>

# Ví dụ: chạy lệnh ls trong container ubuntu
docker exec ubuntu ls

💡 Mẹo nhỏ

Bạn có thể dùng docker exec -it <container> bash để mở một shell mới bên trong container đang chạy, rất hữu ích để kiểm tra hay gỡ lỗi.

V. Kết luận

Trong phần 1 này, chúng ta đã tìm hiểu:

  • Docker là gì, lợi ích so với máy ảo.
  • Cách cài đặt Docker trên Windows, Ubuntu, CentOS.
  • Khái niệm Docker Image và các lệnh: images, search, pull, rm, save, load, tag.
  • Khái niệm Docker Container và các lệnh: run, ps, start, attach, stop, rm, exec, commit.

Phần tiếp theo sẽ đi sâu vào Docker Network, Volume, và Docker Compose để quản lý multi-container.
