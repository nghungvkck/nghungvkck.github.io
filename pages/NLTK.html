NLTK: Thư viện Xử lý Ngôn ngữ Tự nhiên cho Python (Chi tiết)

Ngày đăng: 11/04/2026 Chuyên mục: Xử lý Ngôn ngữ Tự nhiên (NLP)
#nltk #nlp #python #tokenization #wordnet

I. Định nghĩa NLTK

NLTK (Natural Language Toolkit) là thư viện mã nguồn mở hàng đầu cho Python trong lĩnh vực Xử lý Ngôn ngữ Tự nhiên (NLP). Được phát triển từ năm 2001 tại Đại học Pennsylvania, NLTK cung cấp các công cụ và tài nguyên để xử lý văn bản, phân tích ngữ nghĩa, và xây dựng hệ thống xử lý ngôn ngữ. Thư viện bao gồm các mô-đun cho tokenization, stemming, tagging, parsing, classification, và nhiều ngữ liệu (corpora) mẫu như sách, báo, từ điển WordNet.

# Cài đặt NLTK
pip install nltk

# Sau khi cài, cần tải dữ liệu (corpora, tokenizers, v.v.)
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('averaged_perceptron_tagger'); nltk.download('brown'); nltk.download('reuters'); nltk.download('gutenberg'); nltk.download('conll2000')"

II. Vai trò của NLTK trong NLP

  • Cung cấp các bước tiền xử lý văn bản: tokenization, loại bỏ stopwords, stemming/lemmatization.
  • Hỗ trợ gán nhãn từ loại (POS tagging) và phân tích cú pháp (parsing).
  • Tích hợp WordNet – cơ sở dữ liệu từ vựng tiếng Anh, hỗ trợ tìm đồng nghĩa, trái nghĩa, siêu từ.
  • Các mô hình phân loại văn bản (Naive Bayes, Maximum Entropy, Decision Tree).
  • Kho ngữ liệu mẫu phong phú (báo, sách, hội thoại, luận án) để thực hành.
  • Phân tích thống kê ngôn ngữ: tần số từ, collocations, n-grams, concordance.

III. Các cú pháp cơ bản

Dưới đây là các thao tác phổ biến và nâng cao khi làm việc với NLTK.

1. Tokenization – Tách câu và từ

import nltk
from nltk.tokenize import word_tokenize, sent_tokenize

nltk.download('punkt')
text = "NLTK is a great library. It helps process natural language. Don't you like it?"
sentences = sent_tokenize(text)
words = word_tokenize(text)
print("Sentences:", sentences)
print("Words:", words)

2. Loại bỏ Stopwords và dấu câu

from nltk.corpus import stopwords
import string

nltk.download('stopwords')
stop_words = set(stopwords.words('english'))
# Loại bỏ stopwords và dấu câu
clean_words = [w for w in words if w.lower() not in stop_words and w not in string.punctuation]
print("Clean words:", clean_words)

3. FreqDist – Đếm tần số từ

from nltk.probability import FreqDist

fdist = FreqDist(clean_words)
print("Top 5 common words:", fdist.most_common(5))
# Vẽ biểu đồ tần số (cần matplotlib)
import matplotlib.pyplot as plt
fdist.plot(10)
plt.show()

4. N-grams và Collocations – Cụm từ phổ biến

from nltk.util import ngrams
from nltk.collocations import BigramCollocationFinder, TrigramCollocationFinder
from nltk.metrics import BigramAssocMeasures

# Tạo bigrams
tokens = word_tokenize("Natural language processing is fun and useful. NLP is everywhere.")
bigrams = list(ngrams(tokens, 2))
print("Bigrams:", bigrams[:5])

# Tìm collocations (cụm từ có ý nghĩa)
finder = BigramCollocationFinder.from_words(tokens)
finder.apply_freq_filter(2)  # chỉ lấy bigram xuất hiện >=2 lần
print("Bigram collocations:", finder.nbest(BigramAssocMeasures.pmi, 5))

5. Concordance – Tra ngữ cảnh của từ

from nltk.book import text1  # Moby Dick
# text1 là một corpus có sẵn (cần import)
text1.concordance("whale")  # hiển thị dòng chứa từ "whale"

6. Stemming và Lemmatization

from nltk.stem import PorterStemmer, WordNetLemmatizer

stemmer = PorterStemmer()
lemmatizer = WordNetLemmatizer()
words_sample = ["running", "ran", "easily", "better", "geese"]
print("Stemming:", [stemmer.stem(w) for w in words_sample])
print("Lemmatization (verb):", [lemmatizer.lemmatize(w, pos='v') for w in words_sample])

7. POS Tagging – Gán nhãn từ loại

nltk.download('averaged_perceptron_tagger')
tagged = nltk.pos_tag(word_tokenize("The quick brown fox jumps over the lazy dog"))
print(tagged)
# [('The', 'DT'), ('quick', 'JJ'), ('brown', 'NN'), ('fox', 'NN'), ('jumps', 'VBZ'), ...]

8. WordNet nâng cao – Đồng nghĩa, trái nghĩa, siêu từ

from nltk.corpus import wordnet as wn

# Lấy synset (tập hợp từ đồng nghĩa)
syn = wn.synsets('good')[0]
print("Definition:", syn.definition())
print("Example:", syn.examples())
print("Hypernyms (siêu từ):", syn.hypernyms())
print("Hyponyms (hạ từ):", syn.hyponyms()[:3])
print("Antonyms (trái nghĩa):", syn.lemmas()[0].antonyms())  # cần có antonyms

# Tìm tất cả đồng nghĩa của 'car'
car_synsets = wn.synsets('car')
for s in car_synsets:
    print(s.name(), s.definition())

9. Chunking – Phân đoạn cụm danh từ

from nltk.chunk import ne_chunk
sentence = "Mark Zuckerberg founded Facebook in 2004."
tagged = nltk.pos_tag(word_tokenize(sentence))
# Phát hiện thực thể (Named Entity Recognition)
entities = ne_chunk(tagged)
print(entities)  # in ra cây có gán nhãn PERSON, ORGANIZATION, DATE

10. Thực hành với Corpus có sẵn – Reuters, Gutenberg, Brown

from nltk.corpus import reuters, gutenberg, brown

# Reuters corpus: các bài báo kinh tế
print("Reuters categories:", reuters.categories()[:5])
print("First fileid:", reuters.fileids()[0])
print("Content:", reuters.raw(reuters.fileids()[0])[:200])

# Gutenberg corpus: sách văn học
print("Gutenberg books:", gutenberg.fileids())
print("Word count in 'shakespeare-hamlet.txt':", len(gutenberg.words('shakespeare-hamlet.txt')))

# Brown corpus: phân loại thể loại
print("Brown categories:", brown.categories())
print("News text sample:", brown.words(categories='news')[:20])

💡 Lưu ý quan trọng

  • Nếu chưa có dữ liệu, dùng nltk.download('tên_package') để tải.
  • Các corpus lớn (như reuters, brown) có thể mất vài trăm MB, cân nhắc khi tải.
  • Để xử lý tiếng Việt, cần tokenizer riêng (pyvi, underthesea) và stopwords tiếng Việt.
  • NLTK chậm hơn SpaCy, thích hợp cho học tập và xử lý dữ liệu nhỏ.

IV. Kết luận

Với các cú pháp trên, bạn đã có thể bắt đầu phân tích và xử lý văn bản bằng NLTK: từ tokenization, loại bỏ stopwords, đếm tần số, phân tích n-gram, tra ngữ cảnh, stemming, lemmatization, gán nhãn từ loại, nhận diện thực thể, và khai thác các corpus chuẩn. NLTK là công cụ tuyệt vời để học NLP và xây dựng prototype. Phần tiếp theo sẽ giới thiệu SpaCy – thư viện nhanh hơn cho các ứng dụng thực tế.
