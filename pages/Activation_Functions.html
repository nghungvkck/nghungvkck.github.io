Các hàm kích hoạt trong mạng nơ-ron

Ngày đăng: 16/04/2026 Chuyên mục: Deep Learning cơ bản
#activation-functions #neural-network #relu #softmax

I. Định nghĩa

Hàm kích hoạt (Activation Function) là một hàm phi tuyến được áp dụng lên đầu ra của mỗi nơ-ron (sau phép biến đổi tuyến tính \(z = \mathbf{w}^T\mathbf{x}+b\)). Nó quyết định xem nơ-ron có "kích hoạt" hay không và giá trị đầu ra truyền sang tầng tiếp theo. Nếu không có hàm kích hoạt phi tuyến, mạng nơ-ron dù có nhiều lớp cũng chỉ tương đương với một phép biến đổi tuyến tính, không thể học các mối quan hệ phức tạp.

Hàm kích hoạt thường được yêu cầu: khả vi (để backpropagation), đơn điệu, và ổn định về mặt số học.

II. Các hàm kích hoạt phổ biến

1. Sigmoid (Logistic)

\[ \sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z)) \]

Đồ thị: Dạng chữ S, đầu ra trong khoảng (0, 1). Ưu điểm: Trơn, khả vi, đầu ra có ý nghĩa xác suất. Nhược điểm: Bão hòa (gradient rất nhỏ khi |z| lớn → vanishing gradient), không zero-centered (gây khó hội tụ). Dùng: Tầng đầu ra của phân loại nhị phân (kết hợp BCE loss).

2. Tanh (Hyperbolic Tangent)

\[ \tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} = 2\sigma(2z) - 1, \quad \tanh'(z) = 1 - \tanh^2(z) \]

Đồ thị: Dạng S đối xứng tâm, đầu ra (-1, 1), zero-centered. Ưu điểm: Khắc phục được zero-centered của sigmoid, gradient mạnh hơn khi z gần 0. Nhược điểm: Vẫn bão hòa và vanishing gradient ở hai đầu. Dùng: Thường dùng trong RNN (ít hơn hiện nay) hoặc lớp ẩn nhỏ.

3. ReLU (Rectified Linear Unit)

\[ \text{ReLU}(z) = \max(0, z), \quad \text{ReLU}'(z) = \begin{cases} 1 & \text{nếu } z>0 \\ 0 & \text{nếu } z \le 0 \end{cases} \]

Đồ thị: 0 với z≤0, tuyến tính với z>0. Ưu điểm: Tính toán nhanh, không bão hòa ở vùng dương (giải quyết vanishing gradient), thúc đẩy sparse activation. Nhược điểm: Chết ReLU (Dying ReLU) – nếu nhiều z≤0, nơ-ron không bao giờ kích hoạt → gradient 0. Dùng: Là mặc định cho hầu hết các tầng ẩn trong CNN, MLP.

4. Leaky ReLU và Parametric ReLU (PReLU)

\[ \text{LeakyReLU}(z) = \begin{cases} z & \text{nếu } z>0 \\ \alpha z & \text{nếu } z \le 0 \end{cases}, \quad \alpha \text{ nhỏ (0.01)} \]

PReLU coi \(\alpha\) là tham số học được. Ưu điểm: Khắc phục Dying ReLU (vẫn có gradient khi z<0). Nhược điểm: Thêm một tham số (PReLU) hoặc chọn α (Leaky). Dùng: Khi gặp hiện tượng nhiều nơ-ron chết.

5. Softmax (cho tầng cuối đa lớp)

\[ \text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}} \]

Đồ thị: Biến vector logits thành phân phối xác suất. Ưu điểm: Đầu ra có tổng bằng 1, có ý nghĩa xác suất. Dùng: Bắt buộc ở tầng cuối của phân loại đa lớp, kết hợp cross-entropy.

Hướng dẫn chọn:

  • Lớp ẩn: Bắt đầu với ReLU. Nếu có Dying ReLU, chuyển sang Leaky ReLU hoặc ELU.
  • Lớp đầu ra cho hồi quy: Không dùng kích hoạt (linear).
  • Lớp đầu ra cho phân loại nhị phân: Sigmoid.
  • Lớp đầu ra cho phân loại đa lớp: Softmax.
  • Mô hình sâu, lớn: Có thể thử Swish hoặc GELU (tốn thời gian tính).

📌 Mã minh họa vẽ đồ thị các hàm (dùng matplotlib)

import numpy as np
import matplotlib.pyplot as plt

def sigmoid(z): return 1/(1+np.exp(-z))
def tanh(z): return np.tanh(z)
def relu(z): return np.maximum(0,z)
def leaky_relu(z, alpha=0.01): return np.where(z>0, z, alpha*z)
def elu(z, alpha=1.0): return np.where(z>0, z, alpha*(np.exp(z)-1))
def swish(z): return z * sigmoid(z)

z = np.linspace(-5,5,200)
plt.figure(figsize=(12,8))
plt.plot(z, sigmoid(z), label='Sigmoid')
plt.plot(z, tanh(z), label='Tanh')
plt.plot(z, relu(z), label='ReLU')
plt.plot(z, leaky_relu(z), label='Leaky ReLU (0.01)')
plt.plot(z, elu(z), label='ELU (α=1)')
plt.plot(z, swish(z), label='Swish')
plt.legend()
plt.grid(True)
plt.title("Các hàm kích hoạt")
plt.show()
