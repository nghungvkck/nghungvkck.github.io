Perceptron: Mạng nơron đơn lớp

Ngày đăng: 13/04/2026 Chuyên mục: Neural Networks cơ bản
#perceptron #neural-network #classification

I. Định nghĩa Perceptron

Perceptron là mô hình mạng nơron nhân tạo đơn giản nhất, được Frank Rosenblatt đề xuất năm 1958 dựa trên nền tảng nơron nhân tạo của McCulloch và Pitts. Perceptron dùng cho bài toán phân loại nhị phân với giả định dữ liệu là tách biệt tuyến tính.

Cấu trúc một perceptron gồm:

  • Các đầu vào: \(x_1, x_2, ..., x_n\) (các đặc trưng).
  • Các trọng số: \(w_1, w_2, ..., w_n\) và một ngưỡng (bias) \(b\).
  • Hàm kích hoạt: hàm bước (step function) – thường là hàm dấu (sign) hoặc bước Heaviside.

Đầu ra dự đoán \(\hat{y}\) được tính bằng cách lấy tổng trọng số đầu vào cộng bias, sau đó áp hàm kích hoạt:

\[ \hat{y} = \text{sign}\left( \sum_{i=1}^{n} w_i x_i + b \right) \]

trong đó hàm dấu trả về \(+1\) hoặc \(-1\) (hoặc 1/0 tùy cách đặt nhãn).

II. Toán học

Xét bộ dữ liệu huấn luyện gồm \(m\) mẫu \(\{( \mathbf{x}^{(i)}, y^{(i)} )\}\), với \(y^{(i)} \in \{-1, +1\}\). Perceptron xây dựng một siêu phẳng quyết định có dạng:

\[ \mathbf{w}^T \mathbf{x} + b = 0 \]

Lớp của một mẫu được xác định bởi dấu của biểu thức này:

\[ \hat{y} = \text{sign}(\mathbf{w}^T \mathbf{x} + b) \]

Mục tiêu là tìm bộ trọng số \(\mathbf{w}\) và \(b\) sao cho mọi mẫu trong tập huấn luyện được phân loại đúng:

\[ y^{(i)} (\mathbf{w}^T \mathbf{x}^{(i)} + b) > 0 \quad \forall i \]

Để đơn giản hóa, bias có thể được đưa vào vector trọng số bằng cách thêm một chiều cố định 1 vào \(\mathbf{x}\). Khi đó:

\[ \mathbf{w} := [w_1, w_2, \dots, w_n, b], \quad \mathbf{x} := [x_1, x_2, \dots, x_n, 1] \]

và điều kiện trở thành \(y^{(i)} (\mathbf{w}^T \mathbf{x}^{(i)}) > 0\).

III. Tối ưu – Thuật toán học Perceptron

Không giống như logistic regression dùng gradient descent trên hàm log loss, perceptron sử dụng một thuật toán lỗi-driven đơn giản: mỗi khi phân loại sai, nó cập nhật trọng số để điều chỉnh siêu phẳng.

Thuật toán:

  1. Khởi tạo \(\mathbf{w} = \mathbf{0}\) hoặc ngẫu nhiên nhỏ.
  2. Lặp lại nhiều epoch (duyệt qua toàn bộ dữ liệu):
    Với mỗi mẫu \((\mathbf{x}^{(i)}, y^{(i)})\):
    • Tính \(\hat{y} = \text{sign}(\mathbf{w}^T \mathbf{x}^{(i)})\).
    • Nếu \(\hat{y} \neq y^{(i)}\) (phân loại sai), cập nhật:
      \[ \mathbf{w} := \mathbf{w} + \eta \, y^{(i)} \mathbf{x}^{(i)} \]
      với \(\eta > 0\) là tốc độ học (thường lấy 1).
  3. Dừng khi không còn lỗi hoặc đạt số vòng lặp tối đa.

Giải thích cập nhật: Nếu phân loại sai, \(y^{(i)} (\mathbf{w}^T \mathbf{x}^{(i)}) < 0\). Cộng thêm \(y^{(i)} \mathbf{x}^{(i)}\) vào \(\mathbf{w}\) làm tăng giá trị \(y^{(i)} (\mathbf{w}^T \mathbf{x}^{(i)})\) lên \( \|\mathbf{x}^{(i)}\|^2 \), giúp mẫu này dần được phân loại đúng.

Định lý hội tụ Perceptron: Nếu dữ liệu tách biệt tuyến tính, thuật toán sẽ hội tụ sau hữu hạn bước. Nếu dữ liệu không tách biệt tuyến tính, thuật toán không dừng (sẽ chạy vô hạn).

📌 Ví dụ minh họa bằng Python

import numpy as np

class Perceptron:
    def __init__(self, eta=1.0, max_epochs=100):
        self.eta = eta
        self.max_epochs = max_epochs
        self.w = None

    def fit(self, X, y):
        m, n = X.shape
        self.w = np.zeros(n)
        for _ in range(self.max_epochs):
            errors = 0
            for xi, target in zip(X, y):
                y_pred = np.sign(np.dot(xi, self.w))
                if y_pred != target:
                    self.w += self.eta * target * xi
                    errors += 1
            if errors == 0:
                break

    def predict(self, X):
        return np.sign(np.dot(X, self.w))

# Dữ liệu AND logic (tách biệt tuyến tính)
X = np.array([[-1, -1], [-1, 1], [1, -1], [1, 1]])
y = np.array([-1, -1, -1, 1])  # AND: chỉ (1,1) cho +1
p = Perceptron()
p.fit(X, y)
print("Trọng số:", p.w)
print("Dự đoán:", p.predict(X))
