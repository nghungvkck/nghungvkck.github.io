MLP - Multi-Layer Perceptron (Mạng nơ-ron nhiều lớp)

Ngày đăng: 15/04/2026 Chuyên mục: Deep Learning cơ bản
#mlp #neural-network #deep-learning

I. Định nghĩa MLP

MLP (Multi-Layer Perceptron) là một mạng nơ-ron nhân tạo gồm nhiều lớp: một lớp đầu vào, một hoặc nhiều lớp ẩn (hidden layers), và một lớp đầu ra. MLP là sự mở rộng của perceptron đơn lớp (Rosenblatt, 1958) với khả năng học các mối quan hệ phi tuyến phức tạp nhờ các hàm kích hoạt phi tuyến ở các lớp ẩn và thuật toán lan truyền ngược (backpropagation).

MLP là nền tảng của hầu hết các mô hình học sâu hiện đại, từ phân loại ảnh (CNN có thể coi là MLP đặc biệt) đến xử lý ngôn ngữ (các biến thể RNN, Transformer).

II. Kiến trúc và Lan truyền xuôi (Forward Propagation)

Một MLP với \(L\) lớp (tính cả đầu ra, không tính đầu vào) được định nghĩa như sau:

  • Lớp đầu vào: \(\mathbf{a}^{[0]} = \mathbf{x}\) (vector đặc trưng).
  • Các lớp ẩn và lớp đầu ra (l = 1..L):
\[ \mathbf{z}^{[l]} = \mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]} \] \[ \mathbf{a}^{[l]} = f^{[l]}(\mathbf{z}^{[l]}) \]

Trong đó:

  • \(\mathbf{W}^{[l]}\) là ma trận trọng số kích thước \(n_l \times n_{l-1}\) (nối từ lớp \(l-1\) sang lớp \(l\)).
  • \(\mathbf{b}^{[l]}\) là vector bias kích thước \(n_l\).
  • \(f^{[l]}\) là hàm kích hoạt (ReLU, sigmoid, tanh, softmax ở lớp cuối).

Hàm kích hoạt phổ biến cho lớp ẩn: ReLU (\(f(z)=\max(0,z)\)) hoặc tanh, sigmoid. Lớp đầu ra dùng softmax cho phân loại đa lớp, sigmoid cho nhị phân, hoặc linear cho hồi quy.

MLP với ít nhất một lớp ẩn và hàm kích hoạt phi tuyến có thể xấp xỉ bất kỳ hàm liên tục nào (theo định lý xấp xỉ phổ dụng – Universal Approximation Theorem).

📐 Ví dụ MLP đơn giản: 1 lớp ẩn, 3 lớp

Vào 2 nút → Ẩn 4 nút (ReLU) → Ra 3 nút (softmax).

import numpy as np

def relu(z):
    return np.maximum(0, z)

def softmax(z):
    exp_z = np.exp(z - np.max(z))
    return exp_z / np.sum(exp_z)

# Khởi tạo ngẫu nhiên (thực tế cần khởi tạo nhỏ)
W1 = np.random.randn(4, 2) * 0.01
b1 = np.zeros((4, 1))
W2 = np.random.randn(3, 4) * 0.01
b2 = np.zeros((3, 1))

# Forward cho một mẫu x (2,1)
x = np.array([[1.0], [0.5]])
z1 = W1 @ x + b1      # (4,1)
a1 = relu(z1)
z2 = W2 @ a1 + b2     # (3,1)
a2 = softmax(z2)
print("Xác suất các lớp:", a2.flatten())

III. Huấn luyện MLP – Backpropagation

Quá trình huấn luyện MLP sử dụng backpropagation (đã trình bày trong bài trước) kết hợp với gradient descent. Các bước chính:

  1. Forward pass: Tính \(\mathbf{z}^{[l]}, \mathbf{a}^{[l]}\) cho toàn bộ mạng và loss \(L\).
  2. Backward pass: Tính gradient của loss theo từng trọng số bắt đầu từ lớp cuối.
  3. Cập nhật trọng số bằng gradient descent (hoặc Adam, RMSprop...).

Công thức tổng quát cho một mẫu (hoặc batch) với mạng L lớp:

\[ \delta^{[L]} = \nabla_{\mathbf{a}^{[L]}} L \odot f'^{[L]}(\mathbf{z}^{[L]}) \] \[ \delta^{[l]} = \left( (\mathbf{W}^{[l+1]})^T \delta^{[l+1]} \right) \odot f'^{[l]}(\mathbf{z}^{[l]}) \quad \text{(l = L-1 ... 1)} \] \[ \frac{\partial L}{\partial \mathbf{W}^{[l]}} = \delta^{[l]} (\mathbf{a}^{[l-1]})^T, \quad \frac{\partial L}{\partial \mathbf{b}^{[l]}} = \delta^{[l]} \]

Trường hợp đặc biệt: Nếu lớp cuối là softmax + cross-entropy, ta có \(\delta^{[L]} = \mathbf{a}^{[L]} - \mathbf{y}\) (rất đẹp). Với MSE + linear đầu ra, \(\delta^{[L]} = \mathbf{a}^{[L]} - \mathbf{y}\).

Ví dụ huấn luyện MLP 1 ẩn (từ đầu, không dùng framework)

import numpy as np

# Dữ liệu XOR (phi tuyến)
X = np.array([[0,0],[0,1],[1,0],[1,1]]).T   # (2,4)
y = np.array([[0,1,1,0]])                    # (1,4)

# Khởi tạo
np.random.seed(1)
W1 = np.random.randn(4,2) * 0.5
b1 = np.zeros((4,1))
W2 = np.random.randn(1,4) * 0.5
b2 = np.zeros((1,1))

lr = 0.5
epochs = 10000

def sigmoid(z):
    return 1/(1+np.exp(-z))

def sigmoid_deriv(a):
    return a*(1-a)

for epoch in range(epochs):
    # Forward
    z1 = W1 @ X + b1
    a1 = sigmoid(z1)
    z2 = W2 @ a1 + b2
    a2 = sigmoid(z2)
    
    # Loss (MSE)
    loss = np.mean((a2 - y)**2)
    
    # Backward
    dL_da2 = 2*(a2 - y) / y.size
    dL_dz2 = dL_da2 * sigmoid_deriv(a2)
    dL_dW2 = dL_dz2 @ a1.T
    dL_db2 = np.sum(dL_dz2, axis=1, keepdims=True)
    
    dL_da1 = W2.T @ dL_dz2
    dL_dz1 = dL_da1 * sigmoid_deriv(a1)
    dL_dW1 = dL_dz1 @ X.T
    dL_db1 = np.sum(dL_dz1, axis=1, keepdims=True)
    
    # Cập nhật
    W2 -= lr * dL_dW2
    b2 -= lr * dL_db2
    W1 -= lr * dL_dW1
    b1 -= lr * dL_db1
    
    if epoch % 2000 == 0:
        print(f"Epoch {epoch}, Loss: {loss:.4f}")

# Dự đoán
print("Kết quả sau huấn luyện:")
print("Dự đoán:", a2.round().flatten())
print("Nhãn thật:", y.flatten())

IV. Các vấn đề và cải tiến trong MLP

  • Overfitting: Dùng regularization (L1, L2), dropout, early stopping.
  • Biến mất / bùng nổ gradient: Dùng ReLU, batch normalization, gradient clipping, khởi tạo trọng số tốt (Xavier/He).
  • Tốc độ hội tụ: Dùng optimizer Adam thay vì SGD thuần.
  • Số lượng nút ẩn và số lớp: Tăng dần, dùng cross-validation.
